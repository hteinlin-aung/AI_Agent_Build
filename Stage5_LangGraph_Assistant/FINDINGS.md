
In Stage 5, I rebuilt my Stage 4b AI agent using LangGraph.js instead of a manually written execution loop. The agent uses the same Qwen3 4B model, eight tools, and system prompt, but LangGraph introduces a structured graph-based architecture using nodes, edges, state management, and conditional routing. Through this process, I learned how LangGraph handles tool execution, conversation memory, human approval through interrupt(), and execution limits. The implementation passed all 49 main tests, 22 verification tests, and 29 parrot-check tests.

During real-world testing, I discovered that using a framework does not make an AI model smarter or eliminate hallucinations. The model sometimes invented system information, misunderstood tool capabilities, and repeated previous answers instead of following new instructions. To address these problems, I introduced two additional graph nodes: a Verify node, which detects answers containing factual data without tool execution, and a Parrot node, which detects repeated answers caused by the model copying its previous responses. I also improved conversation memory by removing declined action responses so the model would reconsider repeated requests instead of blindly copying its earlier answers. After implementing these improvements, the agent successfully passed its final real-model tests.
